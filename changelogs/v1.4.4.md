# Changelog v1.4.4 (2026-07-29)

## 🚀 New Features

### Deployer PHP 8.3 image
- Added `Dockerfiles/deployer/8.3/Dockerfile`
- Published via `.github/workflows/dockerhub-publish.yml`

### MariaDB 12.3, RabbitMQ 4.3 and Nginx 1.30 images
- Added `Dockerfiles/nginx/1.30/` (Dockerfile, `nginx.conf`, `default.conf`, `docker-entrypoint.sh`)
- Added `Dockerfiles/rabbitmq/4.3/` (Dockerfile, `rabbitmq.conf`)
- Magento `2.4.9` requirements bumped in `data/requirements.json`:
  - `mariadb`: `11.8` → `mariadb:12.3` (official image)
  - `redis`: `hiberusmagento/valkey:9` → `valkey/valkey:9-alpine` (official image)
  - `nginx`: `hiberusmagento/nginx:1.28` → `hiberusmagento/nginx:1.30`
  - `rabbitmq`: `hiberusmagento/rabbitmq:4.2` → `hiberusmagento/rabbitmq:4.3`

## 🔄 Backward Compatibility

- Removed the custom `mariadb` Dockerfile in favor of the official `mariadb` image, following the same pattern already used for `11.4`/`11.8`
